System Design Doc

Live Section — How It Works

The #now section of mohit-portfolio aggregates five real-time data sources into a single typographic widget. This document explains each feed, how data flows, and how the heartbeat online-status system works.

01.

Architecture Overview

Live.jsx mounts five independent useEffect hooks on load — each fetching a different API concurrently. All data is stored in local React state and rendered into the two-column layout below the clock.

Feed Source Poll interval How it updates
Online status GitHub Gist (heartbeat) Every 2 min Script on laptop pings Gist every 5 min
Listening Spotify API → Vercel fn Every 30 sec OAuth refresh token → currently-playing endpoint
Last pushed GitHub REST API On load only Public events feed, no auth required

03.

Heartbeat System — Step by Step

setup-heartbeat.sh heartbeat.sh stop-heartbeat.sh GitHub Gist Live.jsx
Run bash setup-heartbeat.sh
Prompts for a GitHub PAT (gist scope). Verifies it against api.github.com/user.
Creates a secret GitHub Gist
POSTs to api.github.com/gists with status.json containing the current timestamp. Extracts the Gist ID from the JSON response using Python.
{"lastSeen": "2026-06-18T01:53:00Z"}
Patches heartbeat.sh & Live.jsx
Uses sed to inject the PAT and Gist ID into heartbeat.sh, and the full raw Gist URL into HEARTBEAT_GIST_URL in Live.jsx.
Commits & pushes Live.jsx
Pushes to ui-redesign branch. Vercel detects the push and redeploys automatically — the portfolio now knows the Gist URL.
Starts heartbeat.sh in background
Saves PID to /tmp/portfolio-heartbeat.pid. Pings the Gist every 5 minutes with a fresh timestamp.
PATCH /gists/:id → {"lastSeen": "<now>"}
Live.jsx polls every 2 min
Fetches the raw Gist. Computes (now - lastSeen) / 60000. If < 10 minutes → isOnline = true, green pulse. If stale → isOnline = false, grey dot.
Run bash stop-heartbeat.sh
Kills the background process, wipes PAT from heartbeat.sh, reverts Live.jsx to empty Gist URL, commits & pushes. Portfolio shows offline within 2 min.
04.

UI Rendering Logic

Clock & Status Indicator

A setInterval(1000) ticks time state every second. Clock is rendered with toLocaleTimeString in Asia/Kolkata timezone. The green/grey dot and text are driven by isOnline state.

// every 1 second
setInterval(() => setTime(new Date()), 1000)

// every 2 minutes
age = (now - lastSeen) / 60_000
setIsOnline(age < 10)

Spotify Widget

When spotify.isPlaying is true: shows album art with a slow-spinning teal border ring, song title (teal, truncated), artist name, and animated equalizer bars (4 CSS @keyframes bars with staggered delays). Clicking links to the Spotify track.
